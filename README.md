# Воркспейс Ютуб

Адрес сайта: https://adventuretimexanax-commits.github.io/youtube-workspace/
Тёмная тема по умолчанию, мягкий ванильно-жёлтый цвет обозначает успех.
При переименовании репозитория изменяется только путь сайта, не его origin;
ключи хранилища оставлены прежними для сохранения локальных данных.

Статический браузерный трекер YouTube-каналов. Откройте index.html либо
разместите файлы на статическом хостинге. Зависимости для запуска не нужны.

## БДшка

Кнопка в верхней панели открывает таблицу аккаунтов. Можно заполнить Gmail,
«Связь с» (необязательная вторая Gmail-почта),
название, подписку и адрес прокси (host:port, например socks5://127.0.0.1:1080).
Добавляйте строки, редактируйте ячейки, переходите между ними клавишей Tab.
Нажмите «Сохранить» для записи изменений; «Отмена» закрывает без сохранения.
Глазик показывает/скрывает почты и прокси; при повторном открытии они скрыты.

Это НЕ хранилище секретов: маскировка не шифрует данные. Не вводите пароли,
ключи 2FA, токены или прокси с логином/паролем. Для них используйте отдельный
менеджер паролей. Обычные поля тоже не защищены от доступа к браузеру или XSS.
Название и подписка — поля метаданных, не место для секретов.

Таблица сохраняется в localStorage под отдельным ключом
uploadtracker:directory:v1. Она не отправляется на сервер, не синхронизируется
между устройствами и не включается в резервную копию календаря.
Очистка данных сайта удалит таблицу. Меню «Удалить все данные» очищает только
календарь; строки таблицы удаляются отдельно с последующим сохранением.
