# Воркспейс Ютуб

Адрес сайта: https://adventuretimexanax-commits.github.io/youtube-workspace/
Только тёмная тема, без переключателя; старый выбор светлой игнорируется.
Тёплый жёлтый #FFD84D обозначает успех.
При переименовании репозитория изменяется только путь сайта, не его origin;
ключи хранилища оставлены прежними для сохранения локальных данных.

Статический браузерный трекер YouTube-каналов. Откройте index.html либо
разместите файлы на статическом хостинге. Зависимости для запуска не нужны.

## БДшка

Кнопка в верхней панели открывает таблицу аккаунтов. Можно заполнить Gmail,
«Связь с» (необязательная вторая Gmail-почта),
название, подписку и адрес прокси (host:port, например socks5://127.0.0.1:1080).
Добавляйте строки, редактируйте ячейки, переходите между ними клавишей Tab.
Нажмите «Сохранить» для записи изменений; «Отмена» закрывает без сохранения.
Глазик показывает/скрывает почты и прокси; при повторном открытии они скрыты.

Это НЕ хранилище секретов: маскировка не шифрует данные. Не вводите пароли,
ключи 2FA, токены или прокси с логином/паролем. Для них используйте отдельный
менеджер паролей. Обычные поля тоже не защищены от доступа к браузеру или XSS.
Название и подписка — поля метаданных, не место для секретов.

Таблица сохраняется в localStorage под отдельным ключом
uploadtracker:directory:v1. Она не отправляется на сервер, не синхронизируется
между устройствами и не включается в резервную копию календаря.
Очистка данных сайта удалит таблицу. Меню «Удалить все данные» очищает только
календарь; строки таблицы удаляются отдельно с последующим сохранением.

## Заморозка каналов

Кнопка «Заморозить канал» под рабочим пространством ставит канал на паузу
с сегодняшнего дня. Карточка покрывается спокойным ледяным слоем с голубой
кромкой и трещинками; календарь серый, без жёлтого свечения. Календарные
отметки во время заморозки заблокированы, настройки и ссылки доступны.
«Разморозить канал» возобновляет отслеживание сегодня. Прошедшие дни паузы
не становятся пропусками; старые пропуски до заморозки не стираются.
Фактические публикации сохраняются, пауза не добавляет фиктивные дни серии.
Интервалы freezePeriods сохраняются вместе с каналом и входят в JSON-бэкап.
Текстуры нарисованы CSS, без сети и постоянной анимации.

## Обзор и работа с каналом

Переключатель «Обзор / Работа» находится под верхней панелью. Обзор показывает
компактные календари в три колонки на широком экране (две на планшете, одну на
телефоне). Каналы на паузе собраны в сворачиваемую группу. «Открыть канал»
переходит к крупному календарю и настройкам; слева доступны все каналы, включая
замороженные. В списке работают стрелки вверх/вниз, Home и End. На телефоне
список становится горизонтальной лентой.

Режим и выбранный канал запоминаются отдельно в `uploadtracker:layout:v1`.
Формат календаря и БДшки не меняется. Черновики настроек сохраняются в памяти
вкладки при переключениях; постоянная запись по-прежнему кнопкой «Сохранить
настройки». Перезагрузка без сохранения черновика его удаляет.

Карточки не используют backdrop-blur и анимацию появления; градиентный фон
не двигается. Изменение отметки обновляет только соответствующую карточку.
Для браузерной регрессии на синтетических данных: установите Python Playwright
и Chrome, затем `python tests/layout_browser.py`.
